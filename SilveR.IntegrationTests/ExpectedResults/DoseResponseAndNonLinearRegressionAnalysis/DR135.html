InVivoStat Dose-response Analysis

Response and dose variables

The Resp 1 response is currently being analysed by the Dose-response and Non-Linear Regression Analysis module.

The dose variable (Dose1) has been loge transformed prior to analysis.

The analysis performed is a weighted non-linear regression, using 1/Response^2 as the weighting.

Description of the analysis results

The data was analysed using non-linear regression. The estimate of the maximum of the curve is 1.046. The estimate of the slope coefficient of the curve is 0.907. The estimate of the logED50 of the curve is -3.189. The back-transformed estimate of the ED50 of the curve is 0.041. The minimum of the curve was fixed at 0.

For more information on the theoretical approaches that are implemented within this module, see Bate and Clark (2014).
