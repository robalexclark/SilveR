InVivoStat Dose-response Analysis

Response and dose variables

The Resp9 response is currently being analysed by the Dose-response and Non-Linear Regression Analysis module and has been loge transformed prior to analysisloge.

The dose variable (Dose1) has been log10 transformed prior to analysis.

The analysis performed is a weighted non-linear regression, using 1/Response as the weighting. 

Warning

One or more responses are negative, which causes the 1/Response weighting to include negative values. Because negative weights cannot be used in this analysis, selecting the 1/Response^2 weighting is recommended instead.
